# 구현 결정

날짜: 2026-11-12. 새 프로젝트로 시작하라는 현재 사용자 요청을 기준으로 기존 프롬프트북의 기본 버전을 구현합니다.

## React·TypeScript·Vite 정적 앱

기초 화음 학습과 기기 내 기록에 서버가 필요하지 않아 정적 SPA를 선택했습니다. React는 공통 작업대·모달·각 학습 모드를 조합하고, TypeScript는 음높이·상태 이벤트·저장 스키마의 경계를 명시합니다. lockfile로 재현 가능한 설치를 제공합니다.

## 도메인 하나에서 음높이와 표기를 도출

MIDI와 기보상 음문자·임시표·옥타브를 따로 보존합니다. 근음 letter의 3도·5도 문자를 먼저 정한 뒤 목표 MIDI에 필요한 임시표를 계산합니다. E♭/D♯ 건반의 물리적 동일성과 학습용 철자를 혼동하지 않습니다. 오선·토큰·오디오가 화면별 정답표를 따로 갖지 않습니다.

## 직접 SVG 기보

기본위치 3화음의 높은음자리표·오선·덧줄·임시표를 표시하는 작은 `Staff` renderer를 선택했습니다. 외부 기보 엔진의 초기 용량과 의존성을 추가하지 않고, 음표 y좌표를 기보 diatonic index에서 정확히 계산할 수 있기 때문입니다. 반음·옥타브·겹임시표의 도메인 fixture와 별도로 실제 SVG 글리프·클리핑·모바일 확대 검수가 필요합니다. 이후 복잡한 리듬·조표·7화음 범위가 추가되면 adapter를 통해 검증된 전문 기보 엔진으로 교체할 수 있습니다.

## 제작 에셋 원본 보존과 CSS 스프라이트

사용자는 제작한 에셋을 그대로 적용하도록 요청했습니다. 생성 이미지 5장과 제공 삽화 2장을 다시 그리거나 래스터 편집하지 않고 `public/assets/`에 복사했습니다. 일곱 파일 모두 출처 원본과 바이트 동일함을 검증했습니다. `visual.tsx`는 CSS 창으로 아틀라스 영역을 표시하고, 토큰은 배경 위치로 12가지 재료를 선택합니다. 모든 음이름·버튼 글씨·이론 도식은 접근 가능한 HTML 또는 SVG입니다.

## 탭 입력과 무음 학습

정밀 드래그를 필수로 하지 않습니다. 슬롯 선택 후 건반·큰 음 버튼을 탭하여 모든 학습을 진행합니다. 무음 경로의 시각 확인과 실제 재생 완료를 다른 evidence로 남겨 접근성과 기록 정확성을 함께 유지합니다.

## 합성음과 취소 가능한 재생 세션

외부 샘플 다운로드 없이 오프라인에서 음을 비교할 수 있도록 Web Audio 합성음을 사용합니다. 동일 음색·음역·길이로 비교하며 매 요청과 정지의 세션 ID로 `resume()` 지연, 예약 음, 늦은 완료 콜백을 취소합니다. 실제 마지막 음이 끝난 경우에만 completed를 반환합니다.

## 기기 내 저장과 백업

localStorage의 앱 전용 키에 버전·설정·진도·레시피를 저장합니다. 저장 실패는 안내하되 현재 세션을 계속합니다. JSON 가져오기는 스키마·미지원 미래 버전·악성 키·중복을 검증하며, 병합과 교체는 기존 기록 백업 후 실행합니다. 타 앱의 기록을 지우는 clear()는 사용하지 않습니다.

## 오프라인과 업데이트

service worker는 앱 셸과 production JS/CSS를 캐시하고 사용자가 연 이미지를 런타임 캐시합니다. 최초 온라인 로드 이전에는 오프라인 실행을 보장하지 않습니다. 새 버전은 대기 상태로 두고 사용자가 적용할 때 기록을 저장합니다. 자기 앱 이름의 캐시만 정리합니다.

## 공개 범위와 후속 기능

새 Site는 개인용 비공개로 등록되었습니다. 최종 체크와 배포는 소유자 세션에서 진행하며, 이 문서는 배포 성공을 증명하지 않습니다. 7화음과 교실용 확장은 X01/X02의 별도 작업으로 남깁니다.
