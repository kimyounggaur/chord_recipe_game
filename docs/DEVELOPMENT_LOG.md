## 실제 수행한 검사

- `node --import tsx --test tests/music.test.ts`: 18개 음악·데이터 테스트 통과.
- 음악 단독 구현 직후 `npm run typecheck`: 통과. 이후 변경이 있으므로 최종 전체 검사가 필요합니다.
- 에셋 5개 ZIP 항목과 제공 삽화 2개를 `public/assets/` 사본과 바이트 비교: 7개 모두 동일.
- `tsx --test` CLI는 환경의 `/tmp` IPC pipe 권한 오류로 실행되지 않아 공식 Node import 경로를 사용하는 명령으로 바꿨습니다. 실제 실행 명령은 `package.json`을 따릅니다.

## 교차 검토에서 발견하고 담당자에게 전달한 항목

- 물리 검은 건반 선택을 D♯라는 이름 때문에 오답 처리하지 않기.
- 자유 연습의 유효 화음은 실제 품질에 맞는 canonical 철자로 보여 주기.
- 튜토리얼 단계별 입력 슬롯 고정, 완료 단계 13의 재개 가드.
- 새 혼합 시도의 시드와 이전 결과 분리, 도장의 단조 보존.
- 저장된 이어하기 모드, 현재 시도의 힌트·문항 index 복원.
- 재생/입력/화면 전환 경합과 실제 완료 evidence 구분.

이 목록은 검토 기록이며 모든 App 수정이 완료됐다는 뜻은 아닙니다. 최종 소스와 회귀 테스트를 확인하고 QA_REPORT에 상태를 확정합니다.
