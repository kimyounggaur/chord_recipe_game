# 코드 레시피 키친

근음과 두 개의 3도를 차례로 쌓아 장·단·감·증3화음을 배우는 모바일 음악 학습 게임입니다. 사용자와 함께 작성한 「코드 레시피 키친 바이브코딩 프롬프트북 v1.0」의 M01~M20을 기준으로 구현합니다.

## 실행

Node.js와 npm을 설치한 환경에서 다음 명령을 사용합니다. 정확한 의존 버전은 `package-lock.json`으로 고정합니다.

```bash
npm ci
npm run dev
```

```bash
npm run typecheck
npm run lint
npm test
npm run build
npm run preview
```

`lint`는 현재 TypeScript 정적 검사와 같습니다. 별도의 ESLint 규칙을 실행하는 명령은 아닙니다. 테스트는 `node --import tsx --test`로 실행하여 별도 IPC 서버를 요구하지 않습니다. `preview`는 `dist`의 로컬 검수용이며 production 서버가 아닙니다.

## 게임 이용

- **처음 배우기:** C 장3화음을 만든 뒤 가운데 음을 내려 C 단3화음과 비교합니다. 두 인접 간격과 근음 기준 간격을 구분합니다.
- **자유 연습:** 12개 대표 근음과 네 화음 종류를 선택하거나 세 음을 자유롭게 바꿉니다. 레시피 펼치기, 반음 이동, 되돌리기와 비교 전 소리 보관을 제공합니다.
- **주문:** 24개 미션을 순서대로 진행하며 다른 근음, 비교, 감·증3화음을 학습합니다. L23은 네 품질의 주문 네 문항으로 구성됩니다.
- **수리:** 기존 접시에서 틀린 음을 찾아 고칩니다. 근음은 유지하고 가운데·맨 위 음을 수정합니다.
- **레시피북:** 획득한 화음의 구성음, 인접 간격, 근음 기준 간격과 소리를 다시 확인합니다.
- **그림 룰북:** 원본 두 삽화를 12장면의 HTML 설명과 함께 제공합니다. 별도 연습 데모를 종료하면 원래 주문으로 돌아옵니다.

음 선택은 슬롯을 고른 뒤 건반 또는 큰 음 버튼을 누르는 방식입니다. 드래그가 필요하지 않습니다. C4~B5의 두 옥타브를 이동하며 사용합니다. 소리 없이도 그림 확인을 통해 학습할 수 있으며 실제 청취와 시각 확인 기록은 구분합니다.

## 음악 규칙

| 종류 | 인접 반음 | 근음 기준 반음 | C 예시 |
|---|---|---|---|
| 장3화음 | 4+3 | 0·4·7 | C–E–G |
| 단3화음 | 3+4 | 0·3·7 | C–E♭–G |
| 감3화음 | 3+3 | 0·3·6 | C–E♭–G♭ |
| 증3화음 | 4+4 | 0·4·8 | C–E–G♯ |

음높이는 MIDI, 악보 철자는 음문자·임시표·기보 옥타브로 관리합니다. C 단3화음은 같은 검은 건반이라도 C–E♭–G로 적습니다. 기본위치 문제는 음급뿐 아니라 슬롯과 옥타브까지 검사합니다.

## 저장과 복구

학습 기록은 브라우저의 앱 전용 `localStorage` 키에 보관됩니다. 계정이나 서버 동기화는 없습니다. 저장 공간이 차단되어도 현재 세션에서 학습할 수 있으나 페이지를 닫기 전 설정에서 JSON 백업을 내려받아야 합니다.

설정의 기록 가져오기는 크기·형식·버전을 검증하고 병합 또는 교체 전에 기존 기록을 백업합니다. 더 새로운 형식의 기록을 임의로 덮어쓰지 않습니다. 새로고침 후 튜토리얼은 체크포인트, 일반 주문·수리는 현재 문항의 시작 상태에서 재개합니다. 재생하던 음은 자동으로 다시 울리지 않습니다.

## 오프라인과 브라우저

HTTPS 또는 localhost에서 service worker를 사용합니다. 첫 온라인 접속과 필수 파일 캐시가 끝나야 오프라인 기본 학습·합성음·저장이 가능합니다. 큰 이미지와 원본 삽화는 요청 후 캐시되므로 아직 열지 않은 파일은 오프라인에서 표시되지 않을 수 있습니다. 앱 업데이트는 사용자가 적용할 때 진행을 저장한 후 이루어집니다.

설치 UI는 브라우저별 지원 상태에 따라 다릅니다. Android Chrome과 iOS Safari 실기기 검수 여부, production 검수 상태는 `docs/QA_REPORT.md`의 최종 기록을 확인합니다.

## 에셋과 구조

사용자가 제작한 글레이징 질감 에셋 5장과 제공 삽화 2장을 원본 바이트 그대로 보존했습니다. 원본 이미지에 글자를 덧그리지 않고 CSS 창으로 스프라이트를 표시하며 실제 음이름·버튼·설명은 HTML/SVG로 제공합니다. 에셋 출처와 원본명은 `public/assets/manifest.json`에 있습니다.

- `src/music.ts`: 프레임워크 독립 음악 엔진
- `src/lessons.ts`, `src/game.ts`: 24미션과 학습 상태·가드
- `src/audio.ts`: 취소 가능한 합성음 서비스
- `src/storage.ts`: 기록 검증·저장·마이그레이션·병합
- `src/App.tsx`, `src/visual.tsx`, `src/styles.css`: 화면·SVG 기보·원본 스프라이트
- `public/sw.js`, `public/manifest.webmanifest`: 오프라인과 설치 메타데이터
- `tests/`: 독립 음악 fixture, 상태, 오디오 경합, 저장 오류 검사

에셋 7장의 원본 합계는 약 12.66MB입니다. ‘원본 그대로 적용’ 요구를 따랐으며 프롬프트북의 첫 필수 다운로드 1.5MB 목표는 초과할 수 있습니다. 실제 첫 방문 전송량과 반응 시간은 별도 측정이 필요합니다. 배포 상태와 남은 검증은 `RELEASE_NOTES.md`에 기록합니다.

7화음(X01), 교실용 시연 확장(X02), 로그인·결제·랭킹·온라인 학습 기록은 이번 기본 버전 범위에 포함되지 않습니다.
